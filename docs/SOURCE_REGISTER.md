## Source handling

`research-manifest.json` is the machine-readable identity record. Section and line references in RESEARCH_SYNTHESIS and ADRs refer to these exact UTF-8 copies; hashes make subsequent source changes visible. The embedded historical citation tokens belong to the original reports and are not reusable web references. R3 includes a bibliography with ordinary URLs; key current technical sources were checked independently and linked in the synthesis. Do not invent a URL for a historical citation token.

Keep primary-source observations, research recommendations, engineering decisions and unverified assumptions separate. Use current upstream docs for APIs and dependency versions at implementation time. Record any conflict with the design source in an ADR. Current upstream checks are not a complete license audit or software benchmark.
