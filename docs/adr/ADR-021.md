# ADR-021: independent source-only JD analysis before personal CV acceptance

- Date: 2026-11-14
- Status: ACCEPTED — independent decision review recorded
- Scope: implementation/review of TASK-011–014 only; task dependencies remain.

## Context

PR #3 is merged at `83497777a03e6e8f642edadff9781c6cdeb741ad`. The reviewed
baseline implementation and TASK-010 intake are integrated. TASK-009 exact
content/final artifact acceptance remains pending; it cannot be inferred from
the user merging source changes. ADR-020 allowed only draft intake before that
personal gate and did not generally waive later dependencies.

The next source-only components consume a saved employer posting, not applicant
facts: extracting quoted requirement candidates, retaining uncertainty,
classifying source cues, normalizing explicit skill terms and versioning user
corrections. Blocking this analysis on private CV approval does not add evidence
to either operation. It delays a separate part of the requested workflow.

## Accepted bounded amendment

Permit implementation and independent review of TASK-011–014 after their
existing reviewed technical dependencies, while TASK-009 personal acceptance
remains open. This amends only the implementation sequence in the plan and
acceptance matrix; it does not release M1/M2 or change any acceptance criterion.
TASK-011 is the first and only implementation task in the current branch.

All analysis is local, bounded and tied to the exact verified raw JD revision,
digest and Unicode-codepoint spans. Original quotes round-trip exactly. Kind
and priority remain separate; unsupported interpretation stays needs_review.
The TASK-011 output is draft, with unspecified priority until TASK-012's reviewed
classification exists. Responsibilities, context, benefits and ambiguous spans
remain distinguishable. Independently reviewed bilingual fixtures are required.

TASK-011 may expose read-only CLI analysis of an existing verified saved job.
It must not mutate intake revisions or create durable requirement approvals.
Later requirement review/correction persistence remains TASK-014; no storage
framework is added speculatively. No LLM, external service, model dependency,
URL fetch, browser, application submission or new Python dependency is enabled.

TASK-009 and the complete M1 gate remain pending until the applicant reviews
the actual current private facts/documents. Full M2 acceptance still requires
M1 plus reviewed TASK-010–016. TASK-015/016 matching and TASK-017 onward retain
their existing gates; source-only analysis does not authorize career matching,
new CV wording, tailoring, final approval or export. Employer text is never
career evidence. Existing profile, receipt and artifact eligibility is unchanged.
