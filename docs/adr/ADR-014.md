# ADR-014: Vertical slices and scope

- Date: 2026-09-08
- Status: **ACCEPTED FOR PLANNING**
- Decision owner: supervising engineer; independent review recorded in `../reviews/`.

## Context and research disagreement

R1 946–1008; R2 666–704; R3 1673–1755.

## Alternatives

Broad 3–5-day prototype; ~10-week automation roadmap; 34–54-day richer system; gated incremental slices.

## Recommendation / decision

M1 real baseline first; M2 requirements/matrix; M3 tested deterministic tailoring; M4 letters/tracker. NLP models, ESCO, DOCX, full localization, UI and integrations are separate later tasks. Embed safety/QA in each slice, not a final hardening phase.

## Trade-offs and consequences

Report estimates cover different products and cannot be averaged. More up-front provenance work makes the tiny demo estimate unrealistic for the requested evidence standard. A working early baseline creates value before AI integration.

## Validation and adoption gate

Milestones require actual test evidence and independent review. M1 personal acceptance requires applicant curation; synthetic output cannot substitute. Each task is bounded and records dependencies/non-goals. Later task estimates are planning ranges, not deadlines.

## Reconsideration

Re-estimate after TASK-005 and M1 with actual elapsed effort; split any task exceeding roughly one focused day.

## History

Initial planning record. Material changes require dated rationale, affected task/acceptance links and an independent review; preserve the previous decision in Git history.
