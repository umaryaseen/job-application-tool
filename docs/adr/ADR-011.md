# ADR-011: Factuality and supported text

- Date: 2026-09-08
- Status: **ACCEPTED FOR PLANNING**
- Decision owner: supervising engineer; independent review recorded in `../reviews/`.

## Context and research disagreement

R1 698–733, 1348; R2 311–316; R3 schema 1061–1671 and test 1808–1814. All demand truth but examples enforce too little.

## Alternatives

Evidence-ID membership; entity/number matching; LLM/NLI judge; constrained compiler of approved text and typed facts.

## Recommendation / decision

Publish only approved exact variants and typed deterministic field formatting, bound to subject/scope and specific reviewed fact/evidence revisions. New text is a proposal until independently checked against its sources and human approved. Validate graph integrity and protected values in code.

## Trade-offs and consequences

Membership proves a reference exists, not that prose is true. Number matching can transplant metrics. A probabilistic judge cannot guarantee entailment. Constrained generation sacrifices free rewriting for enforceable authorization. Real-world truth still depends on honest, accurate source curation.

## Validation and adoption gate

Tests reject empty/dangling/unrelated valid IDs, unpinned documentary references, changed/missing immutable support captures, wrong-employer metrics, negation flips, leadership inflation, exposure-to-expertise, unsupported language/authorization and stale approvals. Cover every visible candidate claim including headings/contact/skills/education; only fixed nonfactual labels are exempt.

## Reconsideration

Expand transformations only with typed semantics, adversarial tests and an ADR review; never replace the invariant with a model confidence threshold.
