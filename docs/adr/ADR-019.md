## Cold-cache correction exposed by CI

The first macOS run measured 77 passed and 5 failed. The real renderer failed at Typst compilation: the adapter supplied a flat bundled directory where Typst requires `preview/rendercv/0.3.0/`, and RenderCV also imports the unbundled `fontawesome:0.6.0`. The old laptop cache concealed both dependencies. The correction stages the bundled package in the proper namespace and checksum-verified public FontAwesome files, setting both Typst package paths to that stage. A separate setup command requires `--download` and pins official source commit/files. No applicant input is sent and baseline rendering remains network-denied. ADR-004 and DEPENDENCIES record the dependency; fresh CI must validate the repair before adoption.
