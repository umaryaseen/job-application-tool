# ADR-018: allow independent draft JD intake before personal CV acceptance

- Date: 2026-11-11
- Status: ACCEPTED — independent decision review recorded
- Scope: TASK-010 only; no change to career-fact, wording or artifact approval.

## Context

The user merged CLEANUP-001 (PR #1, main `0d81aa1`) and requested continued implementation. TASK-009 personal acceptance is not recorded as complete in GitHub. Two current CV bases and an older proposed profile/review package are available privately, but that is not evidence that the current canonical profile or final artifact has applicant approval.

The original task chain makes even storing a pasted vacancy depend on that personal acceptance. Draft JD intake does not read career facts, generate a CV or require an applicant profile; its technical dependencies are already reviewed. Keeping that unrelated dependency would block useful independent work.

## Accepted decision

Allow TASK-010 to depend on the reviewed private filesystem/snapshot foundation (TASK-001 and TASK-008, plus integrated CLEANUP-001) instead of requiring TASK-009's personal acceptance first. Keep TASK-009 explicitly pending. M1 personal acceptance and the overall M2 release gate are unchanged; this exception enables only private draft intake.

The implementation accepts bounded UTF-8 file/stdin, stores exact input and faithful normalized Markdown with hashes, supplied metadata/locale, deduplication and immutable revisions. It must not infer company research, career facts, requirements, fit, approval, submission or outcomes. URLs are metadata, never fetched. No database, provider, UI or new dependency is introduced.

TASK-011 and later feature dependencies are not generally waived by this decision. A real applicant CV still needs current private source reconciliation and exact document approval before release. Imported older profile records remain at their existing review state.
