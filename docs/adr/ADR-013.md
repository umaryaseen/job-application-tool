# ADR-013: German baseline and localization

- Date: 2026-09-08
- Status: **ACCEPTED FOR PLANNING**
- Decision owner: supervising engineer; independent review recorded in `../reviews/`.

## Context and research disagreement

R1 35–54, 291–333; R2 67–127; R3 49, 94–186, 1936–1942.

## Alternatives

Traditional photo/tabular design; single-column English baseline; bilingual document; separate DE/EN output.

## Recommendation / decision

Single-column, photo-free A4, 11 pt body, 20 mm margins, standard headings and 1–2 pages. Experience-led section order; relevant projects optional. First output EN for an English-language German vacancy; schema, input rules and Unicode fixtures support DE immediately. Full approved German output is TASK-025.

## Trade-offs and consequences

Skills-first order in R3 is useful for some technical profiles, but all reports value visible professional evidence. A bilingual CV consumes space. Layout measurements are project defaults, not universal legal rules. Follow an actual portal format/language instruction.

## Validation and adoption gate

Test headings/order/dates/Unicode from M1. Preserve actual title/degree names or approved translations. No inferred CEFR conversion or skill expansion through translation. Page overflow triggers content review, never tiny type or hidden text.

## Reconsideration

Revisit a specific template only with actual recruiter/portal feedback; photo/personal data remain opt-in and outside MVP.

## History

Initial planning record. Material changes require dated rationale, affected task/acceptance links and an independent review; preserve the previous decision in Git history.
