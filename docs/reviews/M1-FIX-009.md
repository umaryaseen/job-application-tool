## Acceptance, architecture and security assessment

The contact ordering and multiplicity projection, URL labels, URL width-guard coverage,
three language assessment formats, v7 identity, fixture-only display updates, and
absence of plan/profile/provenance/selection changes passed static review and the
synthetic probes above. The item width guard uses the intended Raleway 11 pt
measurement, bold lead measurement and bounded failure path. No margin, font-size,
spacing or trusted template source change was found.

The candidate cannot be accepted because F-01 and F-02 violate the central
unbreakable-item/extraction contract for values accepted by the profile schema,
and F-03 permits approved claim text to alter the generated Typst source. The
renderer-dependent acceptance tests and PDF geometry/visual checks also require a
hosted macOS run after these fixes; this checkout cannot provide that evidence.

  non-empty, cannot introduce a leading separator, and rejects all line-separator

  `\r`, U+2028, U+2029 and U+0085.
