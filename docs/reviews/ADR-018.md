# ADR-018 architecture review

Status: **APPROVED WITH FOLLOW-UP** for the proposed presentation policy;
implementation review is separate and remains open.

The independent review confirmed the fixed category allowlist, preservation of
distinct skill IDs and revisions (including meaningful notes), known education
status, omission of unknown degree names, one-sided date display, and the exact
project-overlap rule. It requires implementation verification that the shared
canonical payload is used by fact digests, local review receipts and profile
digests; legacy empty optional fields retain their prior hashes while nonempty
fields require re-review; and the presentation policy version is included in
the trusted build identity.

This review does not approve M1-FIX-003 or change the status of ADR-018 from
its proposed state.
