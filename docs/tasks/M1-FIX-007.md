# M1-FIX-007: Keep slash-joined compounds intact in extracted text

- Base: main after PR #6 (`68aa5369`).
- Branch: `task/009-m1-fix-007`.
- Trigger: independent QA of the first corrected personal baseline found that
  terms such as `CI/CD`, `ISO/DIN` and `rust/corrosion` wrapped after the slash,
  so both extractors read `CI/ CD`. Applicant-tracking systems read that text.

## Scope and acceptance

Extend the M1-FIX-005 atomic-compound rule from hyphens to slashes: a
whitespace-delimited token containing `-` or `/` is emitted as one unbreakable
box, and the existing width guard refuses to build if such a token cannot fit
the A4 content width (no clipping, shrinking or silent splitting). Extracted
text from Poppler and pypdf must equal the TXT rendering. Template identity
changes. No content, selection or typography change.

## Verification

A deterministic sweep test places slash tokens at every line-end position in
one real PDF and requires both extractors to match the TXT exactly (fails on
the previous renderer); an over-width slash token fails before publication;
full suite, Ruff, format, mypy.
